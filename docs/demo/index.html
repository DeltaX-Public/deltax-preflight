Use it

  • GitHub Action Marketplace listingRuns the same local validator in CI with a pinned policy hash. It blocks merge only if the repository owner makes it a required check.
  • Pull request gate recipe Owner-reviewed workflowBase-branch manifest and policy, with the proposal treated as data. Without a required check, the result is advisory.
  • Local MCP adapter Local server setup and bundleExposes the same local validator over stdio. The surrounding application controls trusted inputs and enforcement.

What this does not claim

  • PASS_SINGLE is validation, not authorization or execution. No proposed action runs.
  • No automatic selection. SELECTION_REQUIRED leaves the choice to a person or a separate, authorized process.
  • No factual-truth proof. Evidence is an owner assertion about exact payloads; Preflight cannot establish that facts are true.
  • Blocking merge requires an owner-configured required check. Without it, the result is an advisory signal.
  • MCP exposes the same local validator — not a gate against its caller.
